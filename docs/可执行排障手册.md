# 公共平台排障手册

## 1. 使用原则

先确定当前角色、租户、来源和时间，再读取证据。先区分“服务异常”与“采集失效”，保留原始 UID 与摘要。下面的命令为只读核对示例，命名空间和资源名以当前登记为准；不能把通用症状自动转为重启或删除动作。Neon 领域部署和修复不在当前授权范围。

## 2. 节点过期、失联或压力

在平台健康页比较预期节点、已观察节点、新鲜且就绪和未知数量。预期分母不因失联变小。首先核对来源质量，若后台采集服务停止或身份变化，应恢复采集链路并重新验证，不直接认定节点业务故障。

```sh
kubectl get nodes -o wide
kubectl describe node NODE
kubectl top nodes
kubectl get pods -n ops-observability -l app=ops-worker
kubectl logs -n ops-observability deploy/ops-worker --tail=30
```

节点压力要与 CPU、内存、文件系统、网络及具体时间对齐。历史 Ready 或旧样本不能代替当前状态；采集成功也不能代替实际请求样本。

## 3. 副本没有创建或滚动更新卡住

先看控制器的 ReplicaFailure/Progressing、当前可用副本和配额 hard/used，而不是只统计现存 Pod。配额可能允许稳定态，却没有更新时临时副本的余量。

```sh
kubectl get deployment -n NAMESPACE
kubectl describe deployment NAME -n NAMESPACE
kubectl get resourcequota,limitrange -n NAMESPACE
kubectl get events -n NAMESPACE --sort-by=.lastTimestamp
```

本平台验收实际遇到过此情形：新增采集组件后，自己的命名空间缺少临时 CPU 限额余量，旧接口仍可用，新副本被配额拒绝。处理是为自身更新预留明确资源并检查控制器重新收敛，没有调整其他命名空间或共享节点。扩容前先核对物理容量，不能通过删除其他团队资源解决。

## 4. 指标可达但没有日志或 Trace

`up=1` 只证明抓取端点可读。按链路逐段检查客户端投递失败、客户端证书与服务端名字、入口认证、Collector 拒绝/队列/出口失败、后端当前可读性以及固定租户分区。没有样本、低流量与正常零值分别解释。

```sh
kubectl get pods,services,endpointslices -n ops-observability
kubectl get networkpolicy -n ops-observability
kubectl get networkpolicy -n TENANT_NAMESPACE
kubectl logs -n ops-observability deploy/SOURCE_COLLECTOR --tail=30
```

不要在聊天或日志中打印认证 Header、私钥或原始 Secret。验证跨租户隔离时，应先证明 DNS 正常、自己的入口可达、目标后端从受信任验收位置确实正常，再检查越界被拒绝。

## 5. 同名服务、同名资源或历史数据疑似混淆

确认当前租户与来源 ID，再核对 namespace/cluster UID。service.name 和资源名称不是安全身份。同名新资源不继承旧对象历史；旧 UID 的过期行应保留为历史观察。切换原生租户前的历史分区只能以明确授权的归档来源读取，不能混入新租户。

## 6. 告警确认与恢复

先读取症状、发生时间和来源，再对照请求、日志与链路。确认责任表示有人负责处理，不能宣告服务已恢复。观察规则不再触发后，继续验证实际请求和数据新鲜度。使用审计中的同一告警指纹核对 firing、acknowledged 与 rule-resolved，重复轮询不应重复生成转换通知。

## 7. 登录失败或权限撤销

区分身份源拒绝、当前绑定拒绝与身份存储不可用。撤权需要在每个接口副本检查配置传播，不以单次 401 推断全部副本已收敛。注销失败时不能宣称服务端会话已经撤销。恢复身份库与配置后，实际执行一次签名验证、角色绑定和会话访问，不能只看数据库表行数。

## 8. 数据恢复与回退

保护原库与原卷，先在独立实例恢复。核对加密包摘要、AEAD 校验、数据库快照、原件/附件 SHA256、RLS、去重、身份登录和 outbox 再投影。镜像回退与数据回退分别评估；已经执行的迁移不得改号或改写。单节点本地卷恢复成功不等于自动跨节点存储 HA。恢复动作必须绑定具体发行、配置、数据时间点和验收记录。
